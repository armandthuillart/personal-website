I built Dimsight so a manufacturer could share a custom machine with a client through a link. The client can inspect the model in a browser, without installing CAD software or receiving the original STEP file.

The first version ran file conversion in the browser. I put it there to ship quickly. It became a problem when someone uploaded a lot of files at once. Conversion failed.

By then, the app had converted more than 100 models, so each change felt risky. I thought moving conversion to the server would take one or two weeks. It took two days, about €20 in token costs, and the help of dozens of coding agents.

At first I thought the agents were the problem. Then I asked whether conversion needed to happen in the browser at all. Moving it to the server removed much of the complexity instead of asking agents to work around it. I wrote about the migration [here](/blog/agents).

Dimsight turns STEP files into browser-based 3D presentations. I want clients to be able to inspect a custom machine, check its measurements, and look at its technical drawings in the same place.
