## 1. Frontend (Svelte y Astro)

Trabajo con [Astro](https://astro.build/) para sitios web centrados en el contenido y con [Svelte](https://svelte.dev/) para aplicaciones web. Empiezo todos mis proyectos con [TypeScript](https://www.typescriptlang.org/).

Los últimos modelos de IA son muy buenos con ambos.

## 2. Estilos (Tailwind CSS y Bits UI)

Crear componentes flexibles y accesibles es difícil. O usas (y amplías) una biblioteca de componentes, o creas la tuya. Por eso uso [Bits UI](https://bits-ui.com/).

Ofrece componentes bien diseñados y ampliables, construidos sobre primitivas accesibles y sin estilos. Incluye elementos básicos como botones y campos de entrada, pero también iconos, gráficos y mucho más.

Los componentes se estilizan con [Tailwind CSS](https://tailwindcss.com/), la biblioteca de CSS más adecuada para la IA. ¿Por qué? Puedes colocar fácilmente los estilos junto al marcado. Eso hace mucho más sencillo generar y editar código con herramientas de IA.

## 3. Base de datos (Convex)

[Convex](https://convex.dev/) es mi backend de referencia. Caché de consultas integrada, actualizaciones en tiempo real, migraciones versionadas y seguridad de tipos de extremo a extremo. Simplemente funciona.

## 4. IA (Zed con OpenCode)

Uso [Zed](https://zed.dev/) (y [agentes de programación](/es/blog/agents)) para editar, refactorizar y depurar código.

## 5. Despliegue (Cloudflare)

Despliego en [Workers](https://workers.cloudflare.com/) con [Wrangler](https://developers.cloudflare.com/workers/wrangler/).
